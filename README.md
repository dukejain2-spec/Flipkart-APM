# Flipkart APM 2029 case

Prompt 1 submission: **Bud-e**, which sits between a child and their personal AI agent. Chores get done instantly. For the moments that build a person, it compares how ready the child is with how heavy the task is, and adjusts how much the AI does. Parents get a developmental report, never the chats.

- `DukeJain_IITDelhi/` is the clickable prototype: plain HTML/CSS/JS, no build step, no dependencies. Open `index.html` in a browser. Its own `README.txt` explains the demo.
- To run it on a local server instead: `npm run dev` from this folder, then open the address it prints (http://localhost:3000, or the next free port). It needs Node but no `npm install`.
  - `Missing script: "dev"`: you're on an older copy of the repository. Pull the latest version.
  - `npm: command not found`: install Node (LTS) from nodejs.org, or skip the server and double-click `index.html`.
  - Without Node: `python3 -m http.server 3000 --directory DukeJain_IITDelhi` works too.
- The submission zip (`DukeJain_IITDelhi.zip`) is made from that folder and is not tracked.

Deadline: Sun 25 Oct 2026, 12 noon.
