A learner's licence for your AI agent (prototype)

Open index.html in any browser. No internet needed.

HOW TO OPEN
Double-click index.html. It works in Chrome, Edge, Safari and Firefox.
No internet, server or installation needed.

HOW TO USE
- It's a responsive web app: it fills the browser window and also works on tablets and phones.
- The panel on the left lists the moments (0 to 10). Click any moment, or use "Next moment" (or the arrow keys).
  On small screens the panel opens from the "Moments" button.
- In each chat the teen's message is pre-filled: press Send (or Enter) to continue.
  Tap the option chips to answer, or type your own words: typing picks the closest option.
- "Behind the scenes" (top bar, shortcut B) shows what the product did for each agent reply:
  detector, licence level, instructions, output check and progress.
- "Include Graduation (optional)" in the left panel adds or skips the last moment.
- "Presentation mode" (or H) hides the demo controls; press H again, or the faint "Demo" button, to bring them back.
- "Reset demo" starts over.

NOTES
- Every agent reply is scripted. There are no real AI calls and no network requests.
- Persona: Ananya, 15, Class 10, Pune. Parent: Priya.
- The product name and level names are placeholders: change them at the top of assets/data.js.
- Anything outside the demo path shows "Not part of this prototype."
