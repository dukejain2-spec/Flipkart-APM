Steer: a learner's licence for your AI agent (prototype)

HOW TO OPEN
Double-click index.html. It opens in any browser (Chrome, Edge, Safari, Firefox).
No internet, server or installation needed.

HOW TO USE
- The panel on the left lists 11 moments. Click any moment, or use "Next moment" (or the arrow keys).
- In each chat the teen's message is pre-filled: press Send (or Enter) to continue.
  Tap the option chips to answer; you can also type your own words.
- Press H to hide or show the left panel.
- "Reset demo" in the left panel starts over.

NOTES
- Every agent reply is scripted. There are no real AI calls and no network requests.
- Persona: Ananya, 15, Class 10, Pune. Parent: Priya.
- Anything outside the demo path shows "Not part of this prototype."
